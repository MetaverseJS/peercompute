Cache: bounded road-vector and AWS Terrarium source bytes are retained in a local-only PeerCompute StateManager artifact tier and the same-origin geodata backend. Artifact bytes never enter the replicated Yjs document. NOAA ETOPO requests remain direct-source.

Geometry: OSM Shortbread ocean and non-glacier inland-water flat Cesium buffer polygons at 50% opacity, exact blue degree-one NURBS source-boundary lines, separate display-derived green degree-one NURBS land-side companion lines, building wires, and solid road lines. The green companion is actual geometry, not glow or a second source boundary. Oceans use source-native zero; each inland polygon uses a bounded median of available terrain samples, with an explicit zero fallback until refresh. Road crossings are raised above the matched water level. Detailed Shortbread buffers begin at zoom 5; the whole-world camera truthfully defers them instead of triangulating the global ocean as one unbounded polygon. Terrain contours remain visible actual buffer-line geometry: source-native elevations at or below zero use shoreline blue and positive elevations use green. The base uses no painted GIS canvas, texture glow, blur, bloom, or halo pass. Shortbread publishes boundaries but no measured water elevation, so every water height remains display-only. Terrain: NOAA ETOPO 2022 or AWS Open Data Terrarium. Optional weather is NOAA nowCOAST source raster imagery.
