What is NetViz?
NetViz is a live topology + telemetry view of the PeerCompute network. The center cube is your local node; amber cubes are peers and blue-white icosahedrons are relays. Amber links show direct WebRTC connections, green arcs show relay-facilitated links with a spur to the relay, and blue-white arcs show peers keeping a relay connection (pubsub activity). Pulses indicate message direction along each link. Select a topology + topology ID before connecting; in distributed mode you can drag your cube to change its metric position. Use "Attach demo" to auto-fill topology + room from any running PeerCompute demo tab. Use Display toggles to render P2P topology, IP topology, or both at once. Click any node or edge to inspect detailed stats (bandwidth, addresses, relay/direct mode, NAT hints). For chaos-lab overlays, set ?chaosApi=http://127.0.0.1:8866 and this panel will show live lab topology + scenario state.
