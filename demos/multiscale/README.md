# Multiscale Ladder Demo

Zoomable PeerCompute workbench for the multiscale physics runtime concept.

This first pass is an integrated visualization scaffold, not a scientific simulator. It shows the intended ladder from supergalactic structure down to Schrodinger-style orbital clouds and emits a warm-delta packet with model tier, boundary conditions, closure summaries, refinement requests, and conservation placeholders.

The particle layer is managed through one PeerCompute `ComputeManager`. Solver budgets use scale-separated defaults so cosmology, relativity, stellar/MHD/radiation/hydro field tiles run slower than local molecular/SPH/material loops unless overridden, and the `scale-aware-multirate-v0` governor backs off those coarse/field solvers faster under pressure. ## Model Boundary
The live remote-placement smoke is intentionally narrower than the visual smoke: it validates trusted browser responders executing coarse cosmology solver work on their `ComputeManager` worker pools over a local relay, including advertised NodeKernel peer capacity, scored connected-peer auto-selection, deterministic balanced primary rotation, scoped persistent local reliability telemetry from task outcomes, positive admission `remoteWorkerCapacity`, ordinary runtime cadence promotion, the explicit probe, primary-plus-replica quorum validation, closed-primary promoted-replica failover with an independent matching quorum replica, and per-task `workerId` / `remoteExecution` provenance. It does not yet prove untrusted peer identity, GPU-cluster scheduling, Sybil-resistant trust, or scientific solver accuracy.

The demo is `multiscale-ladder-proxy-v0`. It exists to validate UI flow, scale transitions, packet shape, and visual performance. Scientific mode still requires replacing proxy layers with validated solvers, reference closures, unit metadata, conservation audits, and benchmark gates.
