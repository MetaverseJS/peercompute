# Multiscale Ladder Demo Plan

## Goal
Build the first integrated keystone workbench for the full physics ladder:

```text
atomic / quantum / MD
  -> coarse reactive material
  -> SPH / MPM / finite-volume
  -> human scale
  -> planetary
  -> solar system
  -> galactic
  -> supergalactic
```
